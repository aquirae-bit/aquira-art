# 編集・実装の優先順位

| 優先度 | 今やること | 理由 |
|---|---|---|
| 最優先 | 2ページのテンプレート見出し・プレースホルダーを、上記のH1・リード・本文へ置換する | 本番に残る「Coming Soon」「編集中」「SINGLE_ITEM_ID」を解消し、ブランドの品格と信頼を回復する。 |
| 最優先 | 両ページのSEOタイトルとメタディスクリプションを更新する | ページの意味を、人と検索・AIシステムの双方に明確に伝える。 |
| 高 | 既存フォームの見出し、説明、完了メッセージを更新する | 既存機能を増やさず、控えめで分かりやすい導線へ改善する。 |
| 中 | CTAリンク先の`/private-inquiry`と作品ページが公開済みかを確認する | クリック後の体験が途切れないようにする。 |
| 後でよい | 写真、動画、独自の図解を追加する | 本文の土台とリンク先を整えた後に、一次素材を使い慎重に拡張する。 |
| やらない | 事実確認のない実績・価格・成功保証、過度な緊急性訴求を追加する | Aquiraの心身聖域、独自性、長期信頼を守る。 |
