## 実装方針

1. 本文は `/tokushoho/` の独立ページに集約し、項目見出しと内容を読みやすい定義リスト風に整理する。
2. 全ページ共通フッターに「特定商取引法に基づく表記」リンクを常設する。これによりトップページとランディングページの双方に安全かつ一貫して表示できる。
3. 本番Wix側は、公開中のページ構成を壊さないよう、独立ページ作成と共通フッターへのリンク追加を優先する。公開操作は別途確認を得てから実行する。
4. 受注制作の発送目安に含まれる「約○週間」はユーザー提示原文を保持する。公開前に具体的な週数への差し替え確認が必要。

## Wix編集の確認

Wixダッシュボードでは、`Original-Branch` と `Wix studio version` の選択が提示された。既存監査の判断どおり、公開中サイトの編集対象として `Original-Branch` を使用する。以後の変更は下書き保存・プレビュー確認までに留め、一般公開操作は実行しない。

`Original-Branch` を選択してWixエディターの起動を実行した。ブランチ選択ダイアログは閉じ、ダッシュボードに戻ったため、エディターの読み込み完了を待機して次の画面状態を確認する。

Wixエディターを直接開いた。画面上では「保存」「プレビュー」「公開」「ページを管理」「ページ・メニュー」「レイヤー」が利用可能であることを確認した。公開は実行せず、独立した法定表記ページと共通フッター導線の下書き実装を目指す。

エディターでは開発モードのページコード一覧が表示され、`ToP/ランディングページ#Top`、`ランディングページ令和8年8月15日`、`masterPage` を含む既存ページ構成を確認した。コード領域には「origin/main の最新コードを読み取り専用で表示しています」とあり、コード編集で本番レイアウトを直接変更しない状態である。次の操作では開発モードを閉じ、ページ・メニューまたはレイヤーから共通フッターを編集する。

開発モードのメニューには「開発モードを無効にする」操作が表示された。この操作は既存のVeloコード構成に影響し得るため実行しない。通常編集へ戻すには、無効化ではなくコードパネルを閉じるか、左側の「ページ・メニュー」から独立ページを追加する経路を用いる。
