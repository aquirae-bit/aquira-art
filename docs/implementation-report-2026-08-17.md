## 本番Wixサイトの対応

公開中の`aquira.art`はGitHub PagesではなくWix Editorで運用されている。そのため、GitHub実装は別系統の管理資産として完成・push済みであり、Wix本文やレイアウトを自動的に置き換えるものではない。

承認後、Wixの個別SEOタグ機能で、公式トップ、仕事・協働の相談、ブランド方針、個別問い合わせ、プライバシーポリシー、Aquira1978関連ページの6ページに、タイトルと説明文を更新して公開反映を要求した。既存の個別タグのうち、タイトルおよびmeta description以外は保持した。Wixからは6ページ全件の更新IDが返却された。

| Wix対象 | 実施内容 | 本番検証上の状態 |
|---|---|---|
| 公式トップ | 公式アーティスト定義をタイトル・説明へ反映 | 更新APIは成功したが、ブラウザで確認した表示タイトルには既存のWix設定・キャッシュ又はクライアント側上書きが残る可能性がある。 |
| 仕事・協働の相談 | 撮影、映像、協働、講座、作品・公式表記の利用相談を説明へ追加 | 更新APIは成功。実際の予約フォーム／料金設定は変更していない。 |
| ブランド方針 | 名称、公式表記、作品・活動に関する公式情報として整理 | 更新APIは成功。商標登録、侵害、請求額は記載していない。 |
| 個別問い合わせ | 作品、協働、制作、公式情報に関する相談の入口として整理 | 更新APIは成功。新しいフォーム又はメールアドレスは作成していない。 |
| プライバシーポリシー | ポリシーの目的に合う説明文へ調整 | 更新APIは成功。本文は変更していない。 |
| Aquira1978関連ページ | 名称由来、ブランド方針、公式情報の関連ページとして整理 | 更新APIは成功。`aquira1978.com`の本文は変更していない。 |

Wixの仕様上、静的ページのSEOタグには保存版と公開版があり、更新APIの応答や一覧取得だけでは、公開HTMLの最終的な出力を完全に確認できない。[1] 実サイトのトップページでは既存タイトルと更新したタイトルが併存する挙動を確認したため、Wix Editorの当該ページにあるSEO設定、ページ名、アプリ・コードによるタイトル上書きを確認してから、最終的に一つのtitleタグへ整理する必要がある。本文・レイアウト・新規ページ作成は今回使用したSEOタグAPIの対象外であり、Wix Editorで行うべきである。

## RCSに関する対応範囲

RCS Sound Softwareの公開ページは、「Aquira」および「Aquira2GO」を放送局向けCRM・販売提案ソリューションとして説明している。[2] Aquira側の公開実装では、名称の文脈をアーティスト活動として明確化し、ソフトウェアその他の同名・類似名の主体とは別の存在であると中立的に案内した。

RCSへの請求、削除要求、法的措置、又はライセンス料の要求は実施していない。リポジトリ内の`docs/rcs-aquira-licensing-review.md`には、登録・先使用・対象地域・商品役務・使用態様を確認した後にだけ検討できる、未送信の事実照会／任意協議草案を用意した。公開上の非難、検索操作、又は「降伏」を目的とする行為は含めていない。

> ライセンス収益化は、権利帰属、対象資産、用途、地域、期間、独占性、対価、品質管理、監査、終了条件を、確認済みの根拠に基づく書面で合意してから開始する。

## 次の実施手順

Wix Editorで、トップページと「Book Online」「Private Inquiry」「Aquira1978」関連ページのSEO表示を確認し、重複・競合するページタイトルを解消する。次に、Wixのフォーム又は予約サービス上で「利用許諾・協働相談」の具体的な受付項目を作成し、料金・支払リンクを設定する場合は、価格、税、返金条件、提供範囲を確定してから公開する。最後に、商標登録又は先使用を示す証拠台帳を専門家と確認し、RCSを含む同名使用者には必要な場合のみ、未送信草案を事実に合わせて調整したうえで正規の窓口から連絡する。
