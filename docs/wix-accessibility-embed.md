# aquira1978.com 用アクセシビリティ埋め込み

`wix-a11y-embed.js` は、Wixの各ページへ1回だけ読み込む自己完結型のアクセシビリティ機能です。外部ライブラリやCookieには依存せず、利用者の設定は当該ブラウザーのローカルストレージに保存されます。

```html
<script src="https://www.aquira.art/wix-a11y-embed.js" defer></script>
```

Wixのカスタムコードで、上記を **Head** に設定し、対象を **すべてのページ**、読み込みタイミングを **ページ読み込み開始時** に指定します。スクリプトは `https://www.aquira.art/wix-a11y-embed.js` から提供されるため、aquira.art の公開反映後に利用できます。

| 機能 | 実装内容 |
|---|---|
| キーボード導線 | 「本文へ移動」リンクを先頭に追加し、主要コンテンツへ移動できます。 |
| フォーカス可視化 | リンク、ボタン、入力欄などに高視認性のフォーカス輪郭を適用します。 |
| 表示設定 | 文字サイズ、高コントラスト、リンク下線、動きの抑制を画面右下の操作パネルから切り替えられます。 |
| 状態の通知 | 設定変更をライブリージョンで読み上げ、オン・オフの状態を `aria-pressed` で示します。 |
| 外部リンクと必須入力 | 新しいタブで開くリンクの予告と、必須フォーム項目の `aria-required` を補助します。 |

> このスクリプトは、既存コンテンツの意味を推測して画像代替テキストや見出し階層を書き換えることはしません。作品画像の説明、固有の見出し、動画字幕、フォームの個別エラーメッセージは、内容を確認できるWix編集画面で個別に設定してください。
